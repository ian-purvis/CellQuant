# Security Policy

## Supported versions

Only the latest release and the current `main` branch get fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private reporting instead: go to the [Security tab](https://github.com/ian-purvis/CellQuant/security) and click **Report a vulnerability**.

Say what the problem is, how to trigger it, and which version you used. The maintainer will reply and, if the report is confirmed, fix it in a new release and credit you if you want.

CellQuant runs on your own computer, opens image files you choose, and downloads its installer pieces and Cellpose models over HTTPS. Reports about those paths are the most relevant.
